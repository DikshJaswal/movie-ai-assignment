# Movie Search App

A responsive Movie Search application built with React and Vite.

## Features

- Search movies
- View movie details
- Add and remove favorites (Local Storage)
- Responsive design
- Error and loading states

## Tech Stack

- React
- JavaScript
- Vite
- React Router
- Axios
- CSS

## Project Structure

- components
- pages
- routes
- services
- styles

## Getting Started

```bash
npm install
npm run dev
```
